# 0.25 源码视觉结构复核

结论：已批准设计方向的源码层落地可通过；可进入SDK/安装包验证。此结论不是ArkUI真机视觉验收，也不代表全功能1:1完成。

## 范围和方法
只读当前Index.ets、VideoLayout.ts、UiStyle.ts和10个components；对照已冻结0.24源与用户批准的SVG设计方向。审查中未修改生产文件、未启动另一套构建或浏览器渲染。静态核对全部10个组件继续引用UiStyle，原组件调用名称集合无移除（这是辅助检查，不替代交互测试）。

## 已确认
- 四工具入口：脚本/输出/媒体/设置；现有全部主要面板保留入口。轴参数高级分组而非删字段，运动/同步/轨迹/书签/全部轴值仍可达。
- 颜色、字号、52vp基准、表单/按钮边框及组件语义状态沿同一套tokens。未另创风格。
- 输入短数字字段在≥300vp满足估算时采用并排，长标签仍换行；不改变草稿确认语义。
- 唯一XComponent视频宿主不因工具切换重建；宽屏视频/轨迹与Inspector分区，窄屏上下，Stop在普通顶栏和全屏控制区可达。
- 非视频Inspector高度扣除实际transport/gap/padding：竖屏88vp，横屏32vp，不再使用挤出父区的100%高度。
- 媒体同步入口明确导航脚本并展开对应区域。
- 重复轴标题、轴值双折叠壳已移除；资源重载移入可达详情，繁忙时仍显示取消。
- 输出详情优先；其它目标摘要折叠；空Column已通过ForEach过滤消除，仍用id:generation键。
- 手机与宽屏Inspector均显示真实outputSummary，含连接/启用/待命/故障；未照搬概念稿示例状态。
- 切工具退旧回调令牌而保留草稿entries；没有为视觉改变0.24所有权逻辑。

## 仍需设备验收，不能用源码或概念图证明
- 320/390vp手机竖屏、568及常见宽度横屏、平板横竖、PC窄宽窗口的实际字体度量、行高、空白、滚动最末端及触控命中。
- 中文长标签/长文件名、系统字体放大、软键盘出现时当前编辑/确认取消/Stop仍可达。
- ArkUI Flex百分比与padding、Select原生渲染、Toggle responseRegion、focus/disabled/pressed样式实际表现。
- 视频原比例、全屏/退出、方向切换是否稳定；画面黑边、分区占高与用户实际设备体验。
- 空媒体/无轴/多个输出/故障/待恢复只读/未应用草稿状态的真实屏幕与交互。
- 视觉稿中的山景、数值、已连接、已保存均只是设计示例；完成后的截图必须来自实际运行，不能沿用预览冒充。
