## Typed points

- Custom Curve Points::Set has a bounded typed points array, duration and interpolation. Apply the original ordered Duration setter, Interpolation setter, then the existing collection Reset. Actual scalar changes request sync in order. Collection Reset itself does not request sync; identical points still trigger refresh and empty points retain the original pending-refresh behavior. Phase is not reset.
- SmartLimitPoints::Set changes the points without generic ResetSync. The current portable schema accepts finite 0–100 coordinates with strictly increasing x. Original headless collection accepts order/duplicates; this remains an explicit partial boundary rather than falsely declaring invalid original input.
- At most 4096 points/action and 8192 points/configuration; defensive copies at edit, save, admission and dispatch boundaries. Editing or previewing a payload never dispatches its action.

## Manual transition and authorization

- Axis Value Set/Offset calls the existing original transition state machine. Set clamps its target, active Offset appends without a target clamp; original duration/time=-1 behavior is retained. Finite-input Append arithmetic overflow is atomically rejected before changing its target/duration. No frame or media observation is generated by a command.
- Set/Offset never starts processing, resumes a stopped source, connects or Arms a target. Every mutation closes the dispatch gate until the next genuine pipeline step.
- Explicit “close media and output connections, then start manual preview” is a volatile source admission. It closes/releases media, disarms and confirms closure of all old output connections before source admission (failure/cancellation stays stopped), clears old transitions, starts the paused/NaN original pipeline, and leaves every output unarmed. Configure an enabled axis with transition not bypassed and no active non-bypassed Motion provider; existing script/Motion priority is not silently overridden.
- Each target has a separate default-false pausedManual permission. A current surviving transition contribution can authorize paused fixed output only when manual preview is explicitly active. This is not Motion permission. The original transition emits no polled event; no event is synthesized and polled manual-only output stays unavailable.
- Stop, background, preview/source disconnect, source change, error, cancellation and runtime rebuild revoke manual admission. Stop clears unfinished manual transitions so later starts cannot resume a stopped command. Output disconnect or a received transport terminal fault also revokes the manual preview admission synchronously through the shared owner, after the failing target closes its own gate; all other manual target candidates are cleared before the callback returns. Stale callbacks from replaced sessions cannot revoke a current preview. Ordinary non-manual target failures remain independent. Reconnection does not resume preview or Arm.
- Explicit fixed-mode Arm may save a waiting intent before any scalar exists, only with current ManualPreviewAdmission evidence and the independent target permission. This evidence is not frame authorization. It binds actual epoch/profile/source identity/generation, exact enabled scope and admission revision. The revision changes on source configuration/control mutations, but not on the permitted Value command itself. The first genuine legal transition frame can open dispatch; the original duration=0 command therefore works without racing a human click against its one-frame lifetime.
- Initial absent values and genuine held states show “待命，无输出”; unknown provenance stays invalid and cannot authorize. Pending immediately clears fixed/polled queues and scheduler candidates; late receipts cannot reinstate them. Permission/scope/configuration changes revoke that target's intent. Stopping, disconnecting or replacing the preview revokes all its old intents. A new preview never inherits Arm.
- Original Home can still advance numeric state while manual preview waits. A fixed frame with no surviving manual contribution stays pending even if Home is enabled; it does not emit a manual command or expire the waiting intent. Unknown lineage remains rejected.
- Startup, settings restoration, generic pause and action editing never grant this admission. Manual-preview start clears transitions prepared while stopped. Existing active media playback retains the current strict activePlayback authorization for the configured pipeline.
- Failures or stale async close callbacks cannot complete a canceled start. Same original source/profile/current frame/scope/revision checks remain mandatory; fixed manual authorization cannot be reused for polled or disabled axes.

## Script::SkipGap

- Execute the source implementation against current bound scripts and current private axis indices (read-only observation, not an advanced snapshot). The source checks only that its axis argument is nonempty, then scans every bound enabled runtime axis. It selects the earliest candidate before checking whether it is past/too close, so such a candidate can block later candidates.
- Indices reflect current offset-adjusted pipeline state, but candidate time and comparison remain raw script seconds. After the candidate passes the original threshold, SeekMediaToTime clamps it to finite media duration; do not reject/clamp before that comparison. Lock/bypass do not remove a bound axis from consideration. Preserve this quirk; the selector does not secretly change the source algorithm.
- A seek goes through the existing real media/confirmed seek transaction, with cancellation and armed-intent restrictions. No fake seekDone or media clock is permitted. OHOS additionally requires finite ready media position/duration and finite legal seek bounds; original NaN comparison behavior is not an admission path.
- Actual extracted C# execution is required for the gap edge fixture. No claimed numerical parity based only on a hand-written duplicate.
