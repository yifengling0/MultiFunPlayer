# 0.29真机检查

1. 首页应只显示Download视频列表、搜索与刷新。点视频后进入独立播放器，真实准备完成后开始播放；没有输出设备也能播放。找不到脚本仍可播放视频。配对错误要有明确提示，不能播放旧视频或旧脚本。
2. 点开一项后立刻返回、Stop、切到控制页或后台；慢读取/慢准备结束后不得突然播放。PC失焦后重新回来也不能恢复待执行点击。
3. 播放器点全屏：手机/平板应请求横屏与隐藏系统栏；PC请求系统窗口全屏。检查横竖两侧、刘海/手势条、画面比例、字幕区和52vp停止。退出/Back/Escape/后台应恢复之前方向和布局；系统自行改变的方向不能被旧事务覆盖。某些系统手势提示可由系统保留，不能把它当作应用导航。
4. 控制→脚本：L0…轴标签、常用强度/偏移/反转可达，进阶组一次展开一组，29字段完整。输入未完成文字后折叠、旋转、切轴再回来，原稿应保留且未应用。确认或Enter才提交；旧隐藏回调不能提交。
5. 平板横屏/PC控制页点“收起预览”，检查参数区扩展；再展开不能重开视频、丢草稿或改变轴/输出目标。
6. 控制→连接：选择Serial/TCP/UDP/WebSocket目标；IP/端口或串口/波特率在前部。已连接目标显示锁定原因，点“断开/编辑连接”后才能修改端点，再连接后必须重新Arm。关闭失败必须隔离，不能假成功。恢复设置不自动连接或Arm。
7. CH340/341仍是严格白名单ROM30实验仅写，未实机验证；先按串口诊断说明识别，不把本版UI改善当作新芯片兼容证明。不得连接非本人确认的设备。
8. 检查320×640手机、手机视频横屏、768×1024平板、1024×768平板横屏及PC窄/宽窗。字体放大、IME弹出、列表末尾、全屏故障和真实材质仍需截图/实际触摸验收。

本地构建为unsigned HAP，需要官方签名和部署到自己的兼容设备。此检查不等于已通过设备验收。Git发布仍受单独确认限制。
