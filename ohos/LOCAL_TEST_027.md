# 0.27: 系统材质与确认弹窗，本地验收

本包需要官方工具签名后安装到自己的兼容设备。当前最低 API20；原生沉浸材质从 API26 起动态加载，系统能力与档位决定实际效果。本地编译、模拟回调不证明设备已经显示光感；请同时记录设备型号、系统版本、字体/显示缩放与页面截图。无需连接任何物理输出即可完成以下检查。

1. 在 API20/25 启动，进入设置、输出和媒体。下拉、开关、滑块及确认弹窗应仍可用，设置页应显示标准清晰样式。没有新模块加载或新 API 调用的回归由自动测试覆盖，低版设备运行仍待实测。
2. 在 API26 进入“设置”查看材质请求状态。展开脚本的插值/轴选择、输出的协议/参数选择，观察 Select 控件及真实下拉菜单；切换已有 Toggle、拖动缩放/音量/时间线 Slider，观察系统材质、按压形变与浅色光反馈。不同系统档位可以不同；正文普通按钮、列表、红色 Stop 不承诺相同原生材质。
3. 先编辑数字成未完成的 `1e-`。切换四工具、旋转、调整窗口、打开/关闭下拉，原草稿应保留且未自动应用。Enter/确认才提交；既有时间线和缩放滑块仍实时执行，请不要在真实设备已启用时随意拖动。
4. 新建可删除的测试输出或克隆设备。删除输出、设备轴、设备配置及导出覆盖剪贴板都应先出现系统确认窗。取消、返回、外侧点击不执行；确认一次仅执行一次。不要为测试删除有用配置。
5. 弹窗中应始终可见至少52vp的取消/确认和红色停止，长提示可滚动。实际收到F12应硬停，Escape只取消；Enter/松开/CANCEL不能误确认。测试240/320vp短高、390vp手机、平板分屏和PC窗口，留意屏幕安全区、系统大字和按钮截断。
6. 打开确认后切后台、换工具、旋转或选择另一目标，旧确认不得删除/导出新对象。设备/目标只读状态变化后也不能继续执行。普通关闭弹窗不能提交数字/文字草稿。
7. 把通用错误展示设为弹窗，制造安全的本地输入错误。应显示同一真实系统弹窗；关闭只确认这次通知，持续故障的原因和发送门不能被清除。若系统报告“对话框关闭未确认”，播放/输出立即停止并锁住启动；残留弹窗的Stop仍可硬停。请重启应用，不尝试绕过安全锁。
8. 回归视频：只有一个原生 Surface；切工具/材质加载/弹窗不重建播放器。核对等比显示、原生全屏、播放/暂停与进度。Stop始终关闭发送；恢复配置、弹窗关闭、旋转和重新连接均不得自动Arm。

请反馈实际截图和步骤，特别是下拉菜单、滑块按压、弹窗关闭/返回、系统字体放大。无需提供私密路径、设备串号、凭据或连接未知设备。真实USB/远端协议验收仍沿用各自指南；本轮没有新增Drive、File录制或协议支持。
