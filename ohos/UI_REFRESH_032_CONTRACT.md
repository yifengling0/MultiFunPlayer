# 0.32 UI 重构与自动化验收

## 目标

这一版只改呈现层和验收方式，不改变播放、轴、输出、媒体来源或设置草稿的语义。参考
`harmonyos_samples/sample_in_harmonyos` 的设计语言，把原先“表单堆叠”的控制页改成
HarmonyOS 常见的「中性画布 + 白色卡片 + 单一品牌蓝 + 分段控件 + 紧凑字段」结构。

## 设计基线

- 画布 `#F1F3F5`，卡片 `#FFFFFF`，输入井 `#F4F6F9`；正文 `#182431`，辅助 `#5E6A75`。
- 品牌色 `#0A59F7`；危险 `#C6382F`；成功 `#1B6B4C`；警告 `#8A5A00`。
  颜色对比度由 `tests/ui-refresh-032.test.mjs` 按 WCAG 4.5:1 校验。
- 圆角：控件 12，卡片 20，胶囊 24。页面只保留一个外边距，卡片内部使用 16vp 统一内边距。
- 字号：标题 22 / 区块 18 / 正文 16（紧凑 15）/ 辅助 14。设置字段标签不再使用低于 14 的字号。
- 触控：所有按钮的可见高度可以是 40/42/44vp，但通过 `responseRegion` 恢复到 48vp；全局 Stop
  仍固定在头部，不是滚动内容。`UiStyle.control` 保持 48，测试继续钉住这一底线。

## 主要界面变化

### 头部与工具导航

- 品牌标记（蓝紫渐变方块 + M）、`MultiFunPlayer`/`MFP` 响应式标题、视频/控制分段控件、
  独立 Stop 胶囊。头部使用半透明表面 + 系统模糊 + 细分隔线。
- 四个工具（脚本 / 连接 / 媒体 / 设置）改为同一条 4 段胶囊轨道；选中项白底、蓝字、轻阴影，
  未选中项透明，不再用下划线表示状态。

### 视频库

- 页面标题、视频数量、刷新按钮、搜索框组成明确的首屏层级。
- 每个视频是一张独立卡片：渐变缩略图、标题、视频/脚本状态徽标、详情按钮；空列表有独立空状态卡片。
- 搜索框保留原有键盘/IME 绑定和 `clearLibrarySearch` 生命周期守卫。

### 控制工作区

- 播放/停止输出改成一张紧凑卡片：可用时蓝色实心，不可用时灰色底 + 灰字；停止输出为浅红底红字。
- 媒体工具条由「6 个按钮挤一行」改成 3×2 等宽网格，图标和文字统一 15vp，停止/播放保留语义色。
- 媒体来源不再使用 5 个零散图标按钮：内部/本地视频是两张等宽状态卡，下面依次是 DeoVR 状态、
  「资源与脚本库」、「来源设置」和当前媒体名。
- 视频区域底部控制条改成白色圆角控制卡：播放（主按钮）、浮窗/展开、全屏，统一 40vp
  可见高度、20vp 胶囊圆角；热力图 Canvas 高度 32vp。
- 轴参数：数字字段改为「标签 + 输入」同一行（360vp 起），输入高度 42vp（紧凑 38vp），
  配合 `responseRegion` 保持 48vp 命中；短标签不再各占一整行。
- 设置面板统一为白色 20vp 圆角卡片；`SettingsSectionTitle` 用 4vp 品牌色竖条 + 标题替代旧的下划线。

### 文案

- 设置加载状态改为中文（“设置已加载 · 输出需要明确连接与启用”），并同步更新相关测试。
- 徽标/辅助文本统一到 14vp（`UiStyle.helper`），避免 12vp 的“小字难读”。

## 自动化验收

### 逻辑与界面契约（Node）

```bash
node --test tests/*.test.mjs
```

新增：

- `tests/ui-refresh-032.test.mjs`：调色板对比度、卡片/圆角/字号基线、头部/工具导航/视频控制条结构、
  视频库卡片结构、设置面板卡片壳、旧调色板残留检查。
- `tests/settings-reflection-032.test.mjs`：解析真实配置类，逐一检查 115 个持久化字段在对应设置
  面板或页面中仍有可见控件；同时验证 General/Sync/Playback/Media/Keyboard/Continuous/Output/Axis
  的字段能经 `SettingsSchema.encode → decode` 往返。`rangesByDevice` 是嵌套容器，显式记录为
  “由范围编辑器代表的间接字段”，不允许无理由跳过。

### 真机 UI 冒烟（hdc）

```bash
node tools/ui-automation.mjs
```

脚本会强制停止并重新启动应用，依次进入视频库、脚本、连接、媒体、设置，展开通用设置与运动编辑区，
逐步校验关键文本存在，保存截图和 layout JSON 到 `.hvigor/outputs/ui-automation/`。它使用
`hdc` + `uitest dumpLayout/screenCap/uiInput`，不依赖桌面坐标，也不修改业务数据。同步编辑区在本机
`dumpLayout` 上会出现长时间等待（应用本身仍可操作），因此真机冒烟不遍历该面板；同步字段由
`settings-reflection-032.test.mjs` 和既有 UI 单测覆盖。

### 连接 / 输出（0.32.1 调整）

- “连接”改成三个小页面：设备列表 → 添加设备 → 目标详情；不再把选择器、添加按钮、全部字段和诊断堆在同一张卡里。
- 列表页顶部直接显示“目标 / 已连接 / 已启用（/ 故障）”计数，每个设备一张卡片，显示协议、地址/串口和状态；点击进入详情。
- 添加页用四张协议卡（串口 / TCP / UDP / WebSocket），选择后进入详情填写地址、端口或串口。
- 详情页把“目标主机 / IP”全文输入框和端口放在最前；地址框带示例占位符，端口显示 `1–65535`，并解释“先确认输入，再点连接设备”。
- 动作按钮按状态收敛：未连接只显示“连接设备”；已连接显示“断开连接”；连接且未启用时显示“启用发送”；已启用时显示“停止发送”。
- 进入“连接/设置”时取消浮窗，视频作为页面顶部的固定预览，选项在它下方滚动，不再盖住内容；
  只有用户显式点“浮窗”才进入浮层。脚本/媒体页同样不自动浮窗。
- 视频控制条的停止按钮由单独的 `■` 改为 **“■ 停止”**，只在全屏（头部隐藏）时出现在视频控制条；
  非全屏时使用头部唯一的安全“停止”，避免上下两个停止按钮重复。可见高度 40vp，命中区保持 48vp。

### 平板 / PC 横屏

- 视频库内容宽度上限 980vp 并居中；宽度 ≥900vp 时视频卡片自动排成两列，手机保持单列。
- 控制页继续使用现有断点：宽度 ≥900vp 且未浮窗时，视频预览与 320–480vp 检查器左右并排；
  检查器不会被拉成整屏宽，字段标签/输入仍按 40/56 或 38/60 分配。
- 头部、工具导航、卡片和字段都使用 vp 与百分比，不依赖手机型号；横屏只改变排布方向。
- 已在 MatePad Mini（MLR-AL10，2560×1600 横屏，API 26）验证视频库两列、宽屏控制页并排布局；
  PC/2in1 使用同一断点，但本轮没有真实 PC 设备可做视觉验收。
