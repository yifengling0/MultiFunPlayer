# 0.25 本地视觉与交互检查

使用冻结的未签名 0.25 HAP，通过官方 SDK 在自己的设备上签名部署。先不要连接运动设备。设计概念图仅为示意，请保留实际截图用于反馈，并保留 0.24 候选作对照。

1. 检查手机 240/320/390vp 竖屏与 568×320 横屏、平板 800×1280/1024×768、PC 1280–1920 宽窗口及缩窄窗口。检查系统安全区、旋转和明确选择的横/竖布局。固定停止至少 52vp 高且始终可见；最后一个设置字段必须能滚动到完整显示。视频全屏使用视频栏停止，退出和旋转不应重建 Surface。
2. 逐一展开四个工具及全部面板。检查统一浅底、青色主要/当前操作、白色次级按钮、红色停止，正文18/辅助14字号，无重叠、截断、隐藏操作或重复空卡片。多个输出时当前目标详情优先，其它状态折叠后没有每目标留下的空白间隔。摘要必须反映真实连接、待命、发送和故障。
3. 脚本页先显示缩放、偏移、反转；五组内所有29字段、Motion/曲线、同步、重载和轴值均可找到。媒体页“同步”应切到脚本同步区。Download资源、各媒体源、列表、AB和AutoSkip仍可达。设置页包含通用、输入和设备。
4. 输入未完成或非法文字，例如“1e-”，旋转、缩放、切工具、收起再返回。应保留“未应用”，不改变正式值。Enter/确认仅应用一次；取消恢复正式值。输出地址/范围和曲线坐标重复测试。存在相关未确认输入时，连接/启用不能绕过。切轴、目标、profile或进入后台后，旧回调/异步连接不得覆盖新对象。页面销毁和进程退出会清除临时草稿。
5. 长下拉值测试“全文/收起”和原生选择菜单，检查完整无障碍值、只读、禁用项及字体放大。测试系统大字、IME合成、光标、焦点与外接键盘。这些原生显示和输入行为尚未实机验收。
6. 媒体与输出独立。切工具或布局不得播放、连接、发送或Arm。已有实时滑块仍即时生效。开启快捷键捕获后离开设置，确认捕获已取消。全局停止仍需停止全部目标、取消待办；后台返回或重新连接不得自动Arm。
7. 完成视觉检查后，才用自己明确选择的接收端/USB设备，按 LOCAL_TEST_023 的串口流程或 LOCAL_TEST_020 的网络诊断检查。CH仍是ROM0x30实验仅写，没有设备输入/ACK或硬件兼容保证。只读识别不证明输出已安全验收。记录设备型号、系统版本、窗口尺寸、字体倍率、后端/错误和截图，不附凭据。

实际设备观察与源码几何、mock、SDK通过分别记录。本轮不包含File录制验收。
