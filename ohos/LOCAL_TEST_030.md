# 0.30 真机验收清单（尚未执行）

1. 从 Download 视频列表点开配对视频；切到首页或控制页，视频、声音、播放进度保持连续，预览下热力图与所选轴一致。暂停/继续、快进、切轴、换视频和无脚本视频均检查，不得显示上一视频脚本。
2. 在手机控制页向下滚动超过96vp，视频缩成右下角浮窗，参数可继续滚动。列表末项可滚动到浮窗上方。“展开”回到顶部并恢复大预览；反复展开/浮窗不能重复声音、重开视频、seek、Connect或Arm。首页视频列表同样检查。
3. 进入全屏后，应横屏并隐藏系统栏和应用控制。单击画面只唤出/收起控制；点播放/暂停按钮才改变播放。播放时控制3.5秒后自动隐藏，暂停时保留。拖动进度条期间不能消失；拖完或点热力图后重新计时。Back/Escape可直接退出。
4. 系统锁定旋转、分屏、后台、窗口销毁、快速进出全屏时，检查恢复方向/系统栏和错误提示。失败不能伪称系统全屏；恢复失败有重试入口。系统手势提示可能由系统保留。
5. 隐藏控制后点画面，再点52vp停止；输出必须关闭。后台/失焦/原有故障路径继续fail-closed，不因任何预览切换重新Arm。只用本人确认的设备进行硬件测试。
6. 覆盖320×568手机、390×844、横屏844×390、768×1024平板、1024×768及PC宽窗。检查热力图不被裁掉、字体放大、IME、最下方参数和浮窗触摸穿透。未应用的编辑草稿跨切换保留。

当前是unsigned HAP；本清单不代表设备验收通过。未提供模拟截图冒充实际ArkUI界面。
