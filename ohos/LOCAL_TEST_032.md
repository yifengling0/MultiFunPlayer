# 0.32 本地设备检查清单

本版把控制页改成 HarmonyOS 卡片/分段风格，并新增自动化冒烟。下面是可以在手机上复核的步骤。

## 准备

- 安装 `entry-default-signed.hap`；保持手机与电脑 `hdc` 连接。
- 若要跑自动冒烟：`node tools/ui-automation.mjs`，或设置 `HDC_TARGET`/`HDC`/`ARTIFACT_DIR`。
- 建议先执行 `hdc shell power-shell wakeup` 并保持屏幕常亮。

## 视觉与层级

1. 冷启动进入“视频库”：应有标题、视频数量、刷新、搜索框和独立视频卡片；空列表应出现空状态卡片。
2. 顶部：品牌方块 + 标题、视频/控制分段、红色 Stop；不滚动时 Stop 始终可见。
3. 控制页：播放/停止输出是一张紧凑卡片；不可播放时播放按钮为灰底灰字，不应用高饱和的浅蓝。
   连接/设置页不应出现浮在内容上的视频；视频固定在顶部，内容在其下方滚动。非全屏时只有一个头部“停止”，
   全屏时视频控制条才显示“■ 停止”，两者不应同时出现。
4. 连接页：顶部直接显示“目标 / 已连接 / 已启用”计数；点“添加”进入协议选择页，选 TCP 后详情页
   的“目标主机 / IP”和“目标端口”必须是全宽可输入字段，未填写时“连接设备”保持禁用。
   从列表打开详情时应从顶部开始，地址、端口和“连接设备”不能因为上次的滚动位置而消失。
5. 媒体页：工具条为 3×2 等宽按钮；不得出现“同/步”折行或按钮相互覆盖。
6. PC 接收模拟器：在 PC 上运行 `ohos/tools/tcode-receiver/start.ps1`，手机添加 TCP/UDP 目标指向 PC 的
   局域网地址和对应端口；连接后状态应为“已连接”，只有显式“启用发送”才应进入“已启用”。
   当前构建在视频播放/独立 Motion 下点击“启用发送”会被
   “No current authorized playback frame” 拒绝，接收端不会出现帧；这是需要继续修复的发送门问题。
5. 媒体页来源区：内部/本地视频为等宽状态卡；下面是 DeoVR 行、“资源与脚本库”“来源设置”，
   不应再有 5 个零散小图标。
6. 脚本页：短数字字段（脚本强度、偏移、速度等）标签与输入在同一行；输入高度不超过 44vp 视觉高度，
   点击仍应可靠命中。
7. 设置页：通用/键盘/设备/各子面板为白色 20vp 圆角卡片；区块标题左侧有 4vp 蓝色竖条。
8. 播放器：视频画面、状态胶囊、白色圆角控制卡、热力图、时间滑杆；单击画面暂停/继续。
9. 横屏平板/PC：视频库内容应居中且不超过 980vp 宽；视频多于一条时卡片排成两列；控制页左侧预览、
   右侧检查器并排，检查器不应被拉满整屏。

## 交互回归

1. 点击“通用设置”，切换界面密度为“紧凑”，确认按钮/间距收紧但所有控件仍可点；切回“舒适易读”。
2. 在脚本页切换轴 L0/L1，确认轴参数、曲线、运动编辑器同步切换且不开始播放、不连接输出。
3. 展开“运动与曲线”，修改速度后点确认，确认“未应用”只在真正编辑后出现，取消能恢复。
4. 在媒体页点击“资源与脚本库”，确认返回视频库；点击卡片进入播放器。
5. 在播放器中点击“全屏”，确认系统栏隐藏/恢复；退出全屏后 Stop 仍固定可见。
6. 打开设置中的设备档案，确认它是卡片内折叠区，展开后设备字段仍使用紧凑布局。
7. 旋转屏幕、切后台再回来：确认布局重排、视频会话和设置草稿不丢失。

## 自动冒烟会检查

- 冷启动、视频库、脚本/连接/媒体/设置四个工具、通用设置、运动编辑器均可渲染。
- 进程在整段导航中保持存活。
- 每一步保存截图和 layout JSON 到 `.hvigor/outputs/ui-automation/`。

## 已知问题

- 本机 `uitest dumpLayout` 在同步面板（多个 Toggle）上可能等待很久；应用本身仍可操作。自动冒烟
  因此不进入同步面板，同步字段由 `settings-reflection-032.test.mjs` 覆盖。
- 2in1/PC 窗口缩放、深色模式、系统字体缩放和真实硬件输出尚未在本轮验收；横屏平板已用
  MatePad Mini（2560×1600）验证两列库和并排控制页。
