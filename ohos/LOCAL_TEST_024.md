# 0.24 本地编辑生命周期验收

先用官方SDK给未签名HAP签名并部署到自己的设备。以下流程无需连接物理输出；连接/Arm和串口权限可保持关闭。源码控制器测试已覆盖相应行为，真实ArkUI/IME效果需要记录截图与设备结果。

1. 在轴Scale输入`1e-`，不确认；旋转、窄宽窗口往返、切视频布局、收起再打开。应保留原文与“未应用”，模型不变。确认非法值应显示错误；取消恢复正式值。
2. 同值的L0/R0分别编辑，切轴后旧提交不得作用新轴；切回时兼容草稿应保留。设备profile/输出target同样检查。正式值在其他入口修改后，旧草稿不得覆盖。
3. 输出端口、范围、host/path分别留草稿；连接/Arm不得隐式提交或使用未确认值。Fixed间隔留非法草稿后切Polled，仍可用本目标取消全部恢复。取消只清临时编辑，不断连、不Arm、不写配置。
4. Curve坐标、新点和选中点跨布局保留；拖动中旋转/后台应取消手势，不能稍后补交。Motion Range/Octaves有效回流状态应保持。
5. 后台再回来：文字保留，但旧IME提交、捕获、剪贴板导入、连接完成不能恢复旧操作。当前字段确认后才应用；重新连接仍须明确Arm。
6. 输入映射的未确认数值/点参数不能执行旧动作；已确认的即时开关/下拉仍按原入口语义。全局Stop保持可达且不受文字草稿阻塞。
7. 页面销毁/重启应清临时草稿，已确认配置仍正常恢复且不连接。分别在手机横竖、平板分屏、PC宽窄窗记录设备型号/系统/字体缩放、异常截图和是否有意外保存。

未验证项：真实IME组合串、caret/focus、平台下拉/触摸、USB或远程设备行为。未得到HMOS指定参考链接，当前不是最终视觉重设计。串口测试另见LOCAL_TEST_023.md。
